# Register Customization Skill

## Description
This skill defines the technical workflows for customizing layouts and design systems for clinical user interfaces, balancing clinical professionalism with modern web innovation.

## Operational Capabilities
1. **Typography & Readability**: Selecting clean, legible sans-serif fonts (e.g., *Heebo* and *Rubik* for RTL Hebrew layout) and setting proper font weight scaling.
2. **Clinical Color System**:
   - Primary dark theme background (`#0A192F`).
   - Accents in gold/sand (`#D4AF37`) representing Jerusalem.
   - Secondary highlights in medical cyan/teal (`#00D2FF`) for modern technology representation.
3. **Responsive Grid Systems**: Mapping schedules, speaker profiles, and cards to CSS grid layouts that transition cleanly from 1 column on mobile to 4 columns on desktop.
4. **Interactive Theme Glows**: Using localized HSL radial glows and drop shadows to direct the user's attention without overloading the screen.
